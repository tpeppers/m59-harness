kriipa

This spindly-legged creature scuttles along the jungle canopy in search of unsuspecting prey, which includes just about everything that moves. Island travelers are warned to keep careful watch above, for the deadly grinning lizards have been known to decapitate a grown man in a single blow with their dagger sharp claws.

What killing it does to your karma

Its karma is -50, and a kill is treated as an act whose karma is the negative of the victim's — so killing this creature pushes you towards good.

base = your_karma − (−victim_karma) = your_karma − 50 change = −( base³ / 2500 + 5 × base ) / (11 − swing) % hundredths of a karma point bounded to ±150 for a monster kill — at most 1.5 karma per kill

No karma moves at all in the newbie region, in an arena, or when the victim's karma is neutral. And once you are already further from neutral than your victim in the same direction, killing them does nothing to you.

DropTimer()

{
      ptDrop = $;

      if piRoofState = STATE_JUMPINGDOWN
      {  
         piRoofState = STATE_READY;      
         send(self,@TryAttack,#what=poTarget);
         ptDrop=CreateTimer(self,@DropTimer,2000);          

         return;
      }

      if piRoofState = STATE_READY
      {         
         piRoofState = STATE_JUMPINGUP;
         send(self,@MonsterJumpUp);
         ptDrop=CreateTimer(self,@DropTimer,950);          
         Send(poBrain,@PostAttackTimer,#mob=self,#state=piState);
      }

      if piRoofState = STATE_JUMPINGUP
      {
         piRoofState = STATE_ONROOF;
         piBehavior = (piBehavior & ~AI_NOMOVE);
         send(poOwner,@SomethingChanged,#what=self);
      }

      return;
   }

AttackTimer(timer = $)

We were bashing on something before, and now its time to hit it again.

{
      Send(self,@ClearBehavior,#timer=timer);

      
      if poOwner = $
      {
         debug("Unreachable. Null Owner");
         Send(self,@EnterStateLimbo);

         return;
      }

      if poTarget=$
      {
         Send(self,@EnterStateWait); 

         return; 
      }
      
      send(poBrain,@GetAttackBehavior,#mob=self,#target=poTarget,#behavior=piBehavior);
      
      if poTarget = $
      {
         Send(self,@EnterStateMove);

         return;
      }      

      if not Send(self,@CanReach,#what=poTarget) 
      {         
         Send(self,@EnterStateChase);

         return;
      }

      
      
      
      if random(1,100) < 50
      {
         piState = piState | ESTATE_CLOCKWISE;
      }
      else
      {
         piState = piState & ESTATE_CCLK_MASK;
      }

      if ptDrop = $
      {
         
         piRoofState = STATE_JUMPINGDOWN;
         piBehavior = (piBehavior | AI_NOMOVE);
         send(self,@MonsterJumpDown);
         ptDrop=CreateTimer(self,@DropTimer,1200);
      }

      return;
   }
