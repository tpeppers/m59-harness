The reference character is a mid-game character — 130 max health, dodge 50, parry 40, agility 40, stroke 50, proficiency 50, aim 40, giving defence 585 and offence 605. Those are the same on every page in this bestiary, so the percentages are directly comparable between creatures. Armour is not included — see Armour for what it subtracts.

It attacks with whip damage. Armour resists by type, so what you wear against this creature matters more than how much you wear.

What killing it does to your karma

Its karma is -40, and a kill is treated as an act whose karma is the negative of the victim's — so killing this creature pushes you towards good.

base = your_karma − (−victim_karma) = your_karma − 40 change = −( base³ / 2500 + 5 × base ) / (11 − swing) % hundredths of a karma point bounded to ±150 for a monster kill — at most 1.5 karma per kill

kod/object/active/holder/nomoveon/battler/monster/evilent.kod:188

MonsterCastSpell()

{
      local oSpell, iBase;
      
      iBase = Send(self,@AdjustedChanceBase,#base=piSpell_chance);

      if Random(1,iBase) = 1
         AND Send(self,@SquaredDistanceTo,#what=poTarget) < SPELL_RANGE_SQUARED
         AND Send(poOwner,@LineOfSight,#obj1=self,#obj2=poTarget)
         AND Send(poOwner,@ReqSomethingAttack,#what=self,#victim=poTarget)
      {
         piAnimation = ANIM_ATTACK;
         Send(poOwner,@SomethingChanged,#what=self);
         piAnimation = ANIM_NONE;
         oSpell = Send(SYS,@FindSpellByNum,#num=SID_LIGHTNING_BOLT);
         Send(oSpell,@CastSpell,#who=self,#lTargets=List(poTarget));

         return TRUE;
      }
      
      return FALSE;
   }
