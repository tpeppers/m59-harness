Priestess Zuxana

The perfect servant of Qor the Vile. Shadows deepen where this malevolent woman stands. She has a devious sensuality that she will exploit to turn men and women to succumb to the dark will of Qor. If she can not seduce others to Qor, she would rather see them dead.

What killing it does to your karma

Its karma is -90, and a kill is treated as an act whose karma is the negative of the victim's — so killing this creature pushes you towards good.

base = your_karma − (−victim_karma) = your_karma − 90 change = −( base³ / 2500 + 5 × base ) / (11 − swing) % hundredths of a karma point bounded to ±150 for a monster kill — at most 1.5 karma per kill

No karma moves at all in the newbie region, in an arena, or when the victim's karma is neutral. And once you are already further from neutral than your victim in the same direction, killing them does nothing to you.

CanAddSpell(who = $, num = 0, report = FALSE)

{
      local i, oSpell, bFound;
			
      if who = $ OR num = 0
      { 
         DEBUG("Called CanAddSpell with bad parameters!");
         return FALSE;
      }

      if num = SID_SWAP
      {   	    
         if send(who,@HasSpell,#num=num) 
         {	 
            if report
            { 
               post(self,@SayToOne,#target=who,#message_rsc=qorpriestess_already_have_spell,
	                 #parm1=send(who,@GetName));
            }

            return FALSE;
         }

         bFound = FALSE;
         for i in send(who,@GetSpellList) 
         {	       
  	         oSpell = send(SYS,@FindSpellByNum,#num=send(who,@DecodeSpellNum,#compound=i)); 
  	         if send(oSpell,@GetSchool) = SS_RIIJA
  	            AND send(oSpell,@GetLevel) > 3 
  	         {
  	            
  	            bFound = TRUE;
  	            
  	            break;
            }  
         }
         
	      
         if NOT bFound
         {	       	  
            if report
            { 		 
	            post(self,@SayToOne,#target=who,#message_rsc=qorpriestess_not_ready); 
            }
            
  	         return FALSE;	       
         }
      }

      if num = SID_POISON_FOG
         AND NOT send(who,@CheckPlayerFlag,#flag=PFLAG_PKILL_ENABLE)
      {
         if report
         {
            send(who,@MsgSendUser,#message_rsc=qorpriestess_not_powerful);
         }
         
         return FALSE;
      }

      propagate;
   }
