mollusk creature

A recent arrival to the lands, this giant creature is rather peaceful. It roams the area, looking for food. It rarely attacks people unless it is attacked first. But, be warned, its thick shell and powerful claw make it a tough foe to face.

What killing it does to your karma

Its karma is 90, and a kill is treated as an act whose karma is the negative of the victim's — so killing this creature pushes you towards evil.

base = your_karma − (−victim_karma) = your_karma + 90 change = −( base³ / 2500 + 5 × base ) / (11 − swing) % hundredths of a karma point bounded to ±150 for a monster kill — at most 1.5 karma per kill

MonsterCastSpell()

{
      local iDistance;

      iDistance = Send(self,@SquaredDistanceTo,#what=poTarget);
      if Random(1,100) < THROW_CHANCE
         AND iDistance > Send(self,@GetAttackRange)
         AND iDistance <= ROCK_RANGE_SQUARED
         AND Send(poOwner,@LineOfSight,#obj1=self,#obj2=poTarget)
         AND Send(poOwner,@ReqSomethingAttack,#what=self,#victim=poTarget,
                  #use_weapon=self)
      {
        Send(self,@DoMissileAttack);

        return TRUE;
      }

      return FALSE;
   }
