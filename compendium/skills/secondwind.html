Second wind will give a mighty adventurer the vigor to do strenuous activity even when exhausted. When near exhaustion, this skill will give a boost to vigor. It is useless to rest or eat food to regain stamina for a while after gaining a second wind.

What kind of skill this is

A skill proper is something you invoke, or that fires automatically when its condition is met. It costs vigour, it can fail, and its ability is both the success chance and the size of the effect.

Learning and improving it

Taught by Drechx.

Ability runs 0–99 and rises by use against something hard enough to matter, with a 50% roll on each qualifying use. It also atrophies: stop using a skill and the number falls. See Advancing Your Character.

GetDuration(who = $)

Duration is anywhere from 5 to 10 minutes before Second Wind can be triggered again

{
      local iStamina, iWaitTime;

      iStamina = Send(self,@GetRequisiteStat,#who=who);
      iWaitTime = ((100-iStamina) * Send(self,@GetAbility,#who=who)/100) + iStamina;
      iWaitTime = (600 - (iWaitTime*3)) * 1000;

      return iWaitTime;
   }

DoSkill(who = $)

Do the skill only if player meets the requirements.

{
      
      
      if Send(self,@GetAbility,#who=who) > 0
         AND Send(who,@GetVigor) < viThreshold
      {
         
         Send(self,@AddEnchantmentEffects,#who=who);

         
         Send(who,@StartEnchantment,#what=self,
           #time=send(self,@GetDuration,#who=who));

         
         Send(who,@MsgSendUser,#message_rsc=SecondWind_success);
   
         
         Send(who,@WaveSendUser,#wave_rsc=SecondWind_sound);

         propagate;
      }

      return;
   }

AddEnchantmentEffects(who = $)

Adjusts vigor threshold and amount. Mimics a personal enchantment.

{ 
      local iVigor;
      
      
      Send(who,@SetVigorRestThreshold,#amount=10);

      return;
   }
