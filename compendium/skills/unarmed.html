This is a hand to hand combat move.

What kind of skill this is

A stroke is a way of swinging. You do not invoke it; the weapon picks one, and its ability decides both how often you connect and how hard. Improving a stroke improves every weapon that uses it.

Learning and improving it

No teacher in the world data offers this skill. It is either granted at creation, awarded by a quest, or reserved for monsters.

Ability runs 0–99 and rises by use against something hard enough to matter, with a 25% roll on each qualifying use. It also atrophies: stop using a skill and the number falls. See Advancing Your Character.

ImproveStroke(who = $, Use_weapon = $, target = $)

{
      if random(1,100) > 50 OR NOT send(who,@HasSkill,#num=SKID_BRAWLING)
      {
         send(self,@ImproveAbility,#who=who,#target=target);        
      }
      else
      {
         send(send(SYS,@FindSkillByNum,#num=SKID_BRAWLING),@ImproveAbility,#who=who,#target=target);
      }

     return;
   }
