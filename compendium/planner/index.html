Worth knowing about this loadout

    What happens to this

    Save to the fleet writes substrate/loadouts/<character>.json. From there the keeper reads it every pass: it stops selling what the list protects, sheds what the list says to shed, tops up to the minimums when it is standing at a counter anyway, and reaches for the weapon named here rather than whichever one it happens to be best with. Spell-school and Weaponcraft levels become an ordered acquisition queue: the first unfinished level is the only level the auto-level strategy may buy from, and every ability at that level must be learned before the following row opens. Nothing the list is silent about changes — a loadout adds rules, it does not replace them. With several characters checked, this becomes Apply gear + carry to selected and uses the same preview-before-write flow as the whole-fleet action.

    Apply gear + carry to fleet writes the gear and the desired inventory from this plan into every character's loadout. Schools, skills, sell and keep lists, purse floors, notes and every other field are left exactly as they are. It says what it would do first and needs a second press. It is the same thing as node tools/m59-loadout.mjs <name> --gear-to-fleet --apply, and it does not save the rest of what you have edited here — that is what Save is for.

    Export downloads the same file. Drop it in that directory by hand and it means the same thing; the planner is a convenience, not the format's owner.
